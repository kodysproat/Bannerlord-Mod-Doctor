## Suggested Project Description

Bannerlord Mod Doctor is a free, open-source Windows troubleshooting utility for Mount & Blade II: Bannerlord mod users.

It helps players diagnose common mod setup issues such as missing dependencies, blocked DLLs, duplicate framework DLLs, load-order problems, XML conflicts, and recent crash-log clues.

The tool creates backups before making file changes and provides undo options for load-order sorting and DLL cleanup.

## Suggested Signing Reason

The project distributes a portable Windows executable to Nexus Mods users. Because the executable is unsigned, scanners and Windows trust systems may warn users even though the project is open source and intended for local troubleshooting.

Code signing would help users verify that the executable was produced by the public project and was not modified after release.
